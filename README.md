# CS50x Week 8 — Homepage 🌐

A multi-page personal website built as part of Harvard's CS50x Homepage problem set.

## About the Project

This project helped me practise the fundamentals of front-end web development by creating a personal website with multiple linked pages, responsive layouts, and a small JavaScript interaction.

## Features

- **Home:** Welcome page with an introduction and navigation.
- **About Me:** Introduction, interests, and learning approach.
- **My CS Journey:** Programming topics and learning progress.
- **My Goals:** Short-term and long-term learning goals.
- **Interactive Coding Tip:** A JavaScript button that displays a random programming tip.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## What I Practised

- Structuring web pages with semantic HTML
- Styling elements with CSS selectors and properties
- Using Bootstrap components and responsive grid layouts
- Linking multiple HTML pages through navigation
- Handling click events and updating page content with JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Navigate through the pages and test the interactive coding tip.

## Learning Outcome

This project gave me practical experience combining HTML, CSS, Bootstrap, and JavaScript to build a multi-page website. It also helped me understand how to organize website content and add basic interactivity.

**Part of my ongoing CS50x learning journey.** 🚀
